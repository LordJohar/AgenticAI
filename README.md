# Agentic AI Learning Workspace

```text
AgenticAI/
├── index.html
├── README.md
└── week-01/
    ├── index.html
    ├── assets/
```

## شروع

فایل `index.html` ریشه یا مستقیماً `week-01/index.html` را در مرورگر باز کنید. JavaScript فقط برای پوسته، جست‌وجوی فهرست، کپی کد و ذخیرهٔ محلی پیشرفت مطالعه استفاده می‌شود؛ محتوای اصلی بدون Server قابل خواندن است.

## وضعیت

- هفتهٔ اول: جزوه و مثال‌های پایه تکمیل شده‌اند.
- تحلیل ویدئوها: در انتظار Upload فایل واقعی جلسه‌ها.
