# جزوهٔ فارسی کلاس Agentic AI

این مخزن برای اشتراک جزوه‌های کلاس با همهٔ شرکت‌کنندگان ساخته شده است. محتوای هر هفته دو مسیر روشن دارد:

- **جزوهٔ مشترک کلاس:** بازنویسی آموزشی مطالب تدریس‌شده، بدون انتشار ویدئو یا Transcript خام.
- **مسیر شخصی‌سازی‌شده:** آموزش‌های تکمیلی، مثال‌ها و تمرین‌هایی که برای پیش‌زمینه و نیازهای یک دانشجو طراحی شده‌اند؛ این بخش عمومی است، اما مرجع رسمی کلاس نیست.

## شروع سریع

1. [صفحهٔ اصلی HTML](index.html) را باز کنید؛ Server لازم نیست.
2. اگر مفاهیمی مثل Neural Network، Softmax یا Attention ناآشنا هستند، از [جزوهٔ پیش‌نیاز مشترک](foundations/index.html) شروع کنید.
3. وارد [هفتهٔ اول](week-01/index.html) شوید.
4. برای محتوای تدریس‌شده، [جزوهٔ مشترک کلاس](week-01/class-notes/index.html) را بخوانید.
5. برای توضیح عمیق‌تر و تمرین عملی، وارد [مسیر شخصی](week-01/personal/index.html) شوید.
6. برای پیش‌خوانی هفتهٔ دوم، [راهنمای Prompt، Context و تعامل ساختاریافته](week-02/index.html) را باز کنید.
7. برای دیدن آموزش‌های تکمیلیِ همهٔ هفته‌ها در یک فهرست، [مسیر شخصی یکپارچه](personal/index.html) را باز کنید.

## ساختار مخزن

```text
assets/                     فونت و دارایی‌های مشترک
docs/                       مستندات عمومی مشترک همهٔ هفته‌ها
foundations/                پیش‌نیاز مفهومی از Neural Network تا LLM
personal/                   درگاه واحدِ مسیرهای آموزشی تکمیلی همهٔ هفته‌ها
week-01/
├── class-notes/            جزوهٔ قابل استفاده برای همهٔ همکلاسی‌ها
├── personal/               مسیر آموزشی عمومی اما شخصی‌سازی‌شده
└── sources/                سرفصل و منابع
week-02/
└── study-guide/            پیش‌خوانی عمومی و تفصیلیِ سرفصل‌های هفتهٔ دوم
```

## مرز انتشار و حریم خصوصی

این موارد هرگز وارد Git نمی‌شوند:

- فایل‌های ویدئو و صوت کلاس؛
- Transcript خام و خروجی‌های میانی پردازش؛
- مدل‌های دانلودشده، virtual environment و ابزارهای اجرایی محلی؛
- Secret، فایل `.env` واقعی، مسیرهای سیستم و مشخصات سخت‌افزار شخصی.

روش عمومی ساخت جزوه با ابزارهای محلی در [راهنمای پردازش رسانه](docs/media-workflow.md) مستند شده تا دیگران بتوانند محیط خودشان را بسازند.

## وضعیت

- پیش‌نیاز مشترک: مسیر مفهومی از ریاضی پایه و Neural Network تا Attention، Transformer و LLM آماده است.
- هفتهٔ اول: دو جلسهٔ کلاس، مسیر تکمیلی، تمرین‌ها و مثال‌های Python آماده است.
- هفتهٔ دوم: پیش‌خوانیِ Prompt، Context، Structured Output، Function Calling و Workflow آماده است؛ پس از دریافت ویدئوها با محتوای جلسه تکمیل می‌شود.
- هفته‌های بعدی: با همین قرارداد پوشه‌بندی اضافه می‌شوند.
