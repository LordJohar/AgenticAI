# Agentic AI Learning Workspace

فضای آموزشی فارسی و پروژه‌محور برای بوت‌کمپ Agentic AI.

## شروع مطالعه

1. فایل `index.html` را در مرورگر باز کنید.
2. برای هفتهٔ اول وارد `week-01/index.html` شوید.
3. فصل‌ها به‌صورت HTML مستقل در `week-01/chapters/` قرار دارند.
4. تمرین‌ها، پاسخ‌ها و کدهای Python در پوشه‌های مجزا نگه‌داری می‌شوند.

## ساخت نسخهٔ تک‌فایلی

```bash
python week-01/build_standalone.py
```

خروجی در `week-01/standalone.html` ساخته می‌شود. این فایل Generated است و لازم نیست در Git نگه‌داری شود.

## وضعیت

- هفتهٔ اول: جزوه، تمرین و مثال‌های پایه تکمیل شده‌اند.
- تحلیل ویدئوها: در انتظار Upload فایل واقعی جلسه‌ها.
