# Week 01 — LLM & Python Application Foundations

## محتوای آموزشی

- `index.html`: فهرست و نقطهٔ ورود هفته
- `chapters/`: نوزده فصل HTML مستقل
- `examples/`: مثال‌های Python و مینی‌پروژه
- `exercises/`: تمرین و پاسخ تشریحی
- `sources/`: Snapshot سرفصل و منابع
- `video-inbox/`: قرارداد دریافت ویدئو
