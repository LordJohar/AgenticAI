# Week 01 Syllabus Snapshot

Source checked: 2026-08-22

Official course page: https://quera.org/bootcamp/agentic-ai#headlines

## Course assumptions shown on the page

- Basic Python proficiency is listed as a prerequisite.
- The course page states an expected weekly commitment of approximately 20–25 hours.

## Week 01 — LLM & Python Application Foundations

- LLM capabilities and limits
- Model ecosystem
- Tokens, context, cost, latency
- Python API refresher
- Environment variables and API usage
- Basic error handling

## Scope decision for this package

The educational package expands only the week-one topics above. Later-week topics such as production RAG, advanced agent orchestration, MCP, evaluation pipelines, guardrails, and deployment are mentioned only where necessary to explain a boundary; they are not treated as completed week-one material.
