Cost و Latency

از «API جواب داد» تا طراحی یک سرویس قابل بودجه‌بندی و دارای SLO

هزینهٔ یک Request

در مدل‌های Metered، ورودی و خروجی معمولاً نرخ جدا دارند. فرمول پایه:

request_cost = (input_tokens / 1,000,000 × input_price) + (output_tokens / 1,000,000 × output_price)
اعداد زیر فقط مثال آموزشی‌اند. قیمت واقعی Provider و Model تغییر می‌کند؛ همیشه Pricing روز را بررسی و قیمت را Configurable نگه دار.

مثال: اگر نرخ فرضی ورودی $2 / 1M و خروجی $8 / 1M باشد، برای ۸٬۰۰۰ Token ورودی و ۱٬۲۰۰ Token خروجی:

(8,000 / 1,000,000 × $2) + (1,200 / 1,000,000 × $8) = $0.0256

عدد یک Request کوچک به نظر می‌رسد، اما با ۱۰۰٬۰۰۰ Request در ماه حدود $2,560 می‌شود؛ قبل از Retry، Evaluation، Development Traffic و Tool Callهای اضافی. برای همین Cost یک Metric عملیاتی است، نه موضوع صرفاً مالی.

Cost Driverهای پنهان

  • ارسال دوبارهٔ تاریخچهٔ طولانی در هر Turn.
  • Retrieval بیش از حد و Chunkهای تکراری.
  • خروجی‌های Verbose یا سقف خروجی نامحدود.
  • Retry بی‌قاعده روی خطاهای غیرقابل Retry.
  • استفاده از مدل بزرگ برای Classification ساده.
  • Agent Loop بدون سقف Step، Time و Budget.
  • Evaluation و Shadow Traffic که در Forecast لحاظ نشده‌اند.

ترتیب بهینه‌سازی

  1. اول معیار کیفیت بساز. بهینه‌سازی بدون Golden Set ممکن است پاسخ سریع و ارزان اما بی‌فایده تولید کند.
  2. خروجی را کوتاه کن. تولید Output معمولاً بخش مهمی از زمان است؛ قالب و سقف روشن بده.
  3. ورودی را تمیز کن. تاریخچه، Tool Output و Retrieval را خلاصه و Deduplicate کن.
  4. تعداد Round-trip را کم کن. چند Call سریالی، Latency و Failure Probability را جمع می‌کنند.
  5. کارهای مستقل را موازی کن. مثلاً دو Retrieval مستقل، نه Stepهایی که Dependency دارند.
  6. مدل کوچک‌تر را پس از اثبات کیفیت امتحان کن.
  7. Cache و Prefix Reuse را بررسی کن. مخصوصاً Instructions ثابت یا پاسخ‌های تکراری.
  8. هر چیزی را LLM نکن. Regex، SQL، Calculator یا Rule Engine برای کار قطعی بهتر است.

نمونهٔ SLO برای یک LLM Feature

# مثال آموزشی، نه نسخهٔ نهایی Production
Availability:      99.5% successful application responses / 30d
Latency:           p95 < 8s for interactive summaries
Quality:           ≥ 90% pass rate on versioned golden set
Citation accuracy: ≥ 98% for evidence-backed answers
Safety:            0 unauthorized tool actions
Cost guardrail:    ≤ $0.04 per successful request at p95

همان‌طور که CPU/RAM Request و Limit را بدون Profiling تعیین نمی‌کنی، Token Budget و Model Tier را هم بدون Trace و Evaluation حدس نزن.
