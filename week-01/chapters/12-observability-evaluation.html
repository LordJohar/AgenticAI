Observability برای LLM Application

Latency و Error کافی نیست؛ باید کیفیت معنایی را هم قابل مشاهده کنیم

چه چیزی Log شود؟

Metadata مفید

  • Timestamp و Correlation ID
  • Provider، Model و Model/Prompt Version
  • Operation یا Feature Name
  • Duration، Retry Count و Status
  • Input/Output Token و Cost Estimate
  • Tool Name، Tool Duration و Result Status
  • Request ID سرویس‌دهنده

چیزی که پیش‌فرض Log نشود

  • API Key، Token، Cookie و Authorization Header
  • Prompt یا فایل کامل حاوی دادهٔ محرمانه
  • PII بدون Masking و Purpose روشن
  • Tool Arguments حساس
  • Chain-of-thought خصوصی یا داده‌ای که Product نیاز ندارد

Metricهای عملیاتی

Metricچرا مهم است؟
llm_requests_totalTraffic بر اساس Feature، Model و Status.
llm_request_duration_secondsp50/p95/p99 و Tail Latency.
llm_input_tokens_total / output_tokens_totalCapacity و Cost Driver.
llm_retry_totalتشخیص Rate Limit، Network Instability یا Retry Storm.
llm_estimated_cost_totalBudget، Forecast و Anomaly Detection.
llm_eval_pass_ratioکیفیت واقعی روی Dataset نسخه‌بندی‌شده.
tool_call_failures_totalخطاهای Agent خارج از خود مدل.

Trace یک Agent

trace: user-request-42
  span: input-validation                  8ms
  span: retrieve-runbook                92ms
  span: llm-plan                       2100ms
  span: tool-k8s-get-events             340ms
  span: llm-final-answer               2850ms
  span: output-policy-check              40ms

Trace نشان می‌دهد تأخیر یا خطا دقیقاً در Retrieval، Model، Tool یا Validation رخ داده است. اما برای AI یک بعد دیگر داریم: پاسخ ممکن است از نظر HTTP و Latency سالم باشد ولی از نظر معنا غلط باشد. اینجا Evaluation وارد می‌شود.

Evaluation چیست؟

مجموعه‌ای از نمونه‌های نسخه‌بندی‌شده و معیارهایی برای سنجش خروجی. بخشی از معیارها قطعی‌اند، مانند JSON Validity یا وجود Citation؛ بخشی نیاز به Rubric، Model Judge کنترل‌شده یا Human Review دارند، مانند «آیا خلاصه علت را درست و بدون حدس بیان کرده؟».

Dashboard سبز می‌تواند دروغ بگوید. اگر فقط HTTP 200، Error Rate و Latency را مانیتور کنی، Semantic Regression دیده نمی‌شود. Prompt و Model را مثل Code Version کن و Evaluation را در Release Gate قرار بده.
