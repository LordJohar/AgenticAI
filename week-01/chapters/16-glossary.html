واژه‌نامهٔ هفتهٔ اول

ترجمهٔ کوتاه اصطلاحاتی که در کلاس پشت سر هم شنیده می‌شوند

AI
عنوان کلی برای سیستم‌هایی که کارهای مرتبط با ادراک، پیش‌بینی، زبان یا تصمیم‌سازی انجام می‌دهند.
Machine Learning
ساخت مدل از داده به‌جای نوشتن تمام قواعد به‌صورت دستی.
Neural Network
ساختار محاسباتی پارامتردار که الگوها را از داده یاد می‌گیرد.
Transformer
معماری شبکهٔ عصبی مبتنی بر Attention که پایهٔ بسیاری از LLMهای امروزی است.
LLM
مدل زبانی بزرگ برای پردازش و تولید دنبالهٔ Tokenها.
Parameter / Weight
اعداد یادگرفته‌شدهٔ داخل مدل که رفتار آن را شکل می‌دهند؛ با Prompt معمولی ویرایش نمی‌شوند.
Training
مرحلهٔ پرهزینهٔ یادگیری Weightها از داده.
Inference
اجرای مدل آموزش‌دیده برای تولید پاسخ به ورودی جدید.
Token
واحد قطعه‌بندی متن برای ورودی و خروجی مدل.
Tokenizer
الگوریتم تبدیل متن به Token ID و برعکس.
Context Window
حداکثر بودجهٔ Tokenهایی که مدل در یک Request می‌تواند پردازش کند، با در نظر گرفتن خروجی.
Prompt
متن و ساختاری که Task، Data و محدودیت‌های پاسخ را به مدل می‌دهد.
System / Instructions
قواعد سطح بالاتر Application برای نقش، سیاست و قالب رفتار مدل.
Temperature
یکی از کنترل‌های Sampling؛ در برخی APIها قابل تنظیم است و بر تنوع خروجی اثر می‌گذارد، نه بر «درست بودن» تضمینی.
Hallucination
تولید ادعای نادرست یا بدون پشتوانه با ظاهر قانع‌کننده.
Grounding
متصل کردن پاسخ به Evidence یا Source مشخص.
Embedding
بردار عددی نمایندهٔ معنا برای Search، Similarity و Clustering.
RAG
Retrieval-Augmented Generation؛ بازیابی Evidence بیرونی و قرار دادن آن در Context قبل از تولید پاسخ.
Tool Calling
مدل نام ابزار و Argument پیشنهادی را تولید می‌کند؛ Application ابزار را Validate و اجرا می‌کند.
Agent
سیستمی که Model را با Instructions، Tools، State، Loop و Guardrail ترکیب می‌کند تا چند Step انجام دهد.
Workflow
جریان عمدتاً از پیش تعریف‌شده؛ در برابر Agent آزادتر و تصمیم‌محورتر.
Structured Output
خروجی مطابق Schema مانند JSON برای پردازش مطمئن‌تر توسط Code.
Fine-tuning
تنظیم بیشتر Weightهای مدل روی Dataset خاص؛ با RAG یا Prompting یکسان نیست.
Model Card
مستند قابلیت، محدودیت، Dataset، License و نتایج ارزیابی مدل.
Open-weight
مدلی که Weightهایش قابل دریافت است؛ لزوماً تمام اجزای آن Open-source نیست.
Quantization
کاهش دقت عددی Weightها برای کم کردن حافظه و افزایش سرعت، با احتمال افت کیفیت.
Evaluation / Eval
سنجش سیستم روی Dataset و معیارهای تعریف‌شده برای کیفیت، ایمنی و رفتار.
Golden Set
مجموعهٔ نمونه‌های نماینده و نسخه‌بندی‌شده برای Regression Test.
Guardrail
کنترل‌های ورودی، خروجی، Tool، Permission و Policy برای محدود کردن رفتار پرخطر.
Rate Limit
سقف تعداد Request یا Token در بازهٔ زمانی.
Latency
زمان پاسخ؛ شامل Network، Queue، پردازش ورودی، تولید خروجی و Toolها.
Streaming
دریافت تدریجی خروجی به‌جای انتظار برای تکمیل کل پاسخ.
SDK
کتابخانهٔ Client برای ساده کردن استفاده از API.
API Gateway
لایهٔ مرکزی برای Auth، Routing، Quota، Logging، Policy و چند Provider.
Idempotency
اجرای چندبارهٔ یک عملیات نتیجهٔ ناخواستهٔ تکراری ایجاد نکند.
Backoff / Jitter
افزایش تدریجی فاصلهٔ Retry و افزودن تصادف برای جلوگیری از Retry Storm.
