چرا کلاس دور به نظر رسید؟

تشخیص شکاف واقعی، بدون برچسب «من چیزی بلد نیستم»

با توجه به سرفصل رسمی، هفتهٔ اول هم‌زمان دو زبان متفاوت را فرض گرفته است: زبان AI/LLM و زبان Python/API. صفحهٔ دوره نیز «تسلط بر پایتون پایه» را پیش‌نیاز اعلام کرده و برای دوره حدود ۲۰ تا ۲۵ ساعت زمان هفتگی در نظر گرفته است. بنابراین کسی که مهندس زیرساخت قدرتمندی است ولی مدتی از کدنویسی روزانه فاصله داشته، ممکن است در کلاس نه به‌خاطر ضعف مفهومی، بلکه به‌خاطر تراکم واژه‌ها و سرعت جابه‌جایی میان این دو زبان جا بماند.

🧠

شکاف مفهومی

LLM، Token، Context، Inference، Hallucination و Model Family اصطلاحات تازه‌اند؛ ولی منطق سیستم پشت آن‌ها برایت غریبه نیست.

🐍

شکاف ابزاری

کلاس احتمالاً سریع از venv، pip، dict، JSON، SDK، Environment Variable و Exception عبور کرده است.

⏱️

شکاف سرعت

وقتی هر واژه نیاز به ترجمهٔ ذهنی داشته باشد، تا معنای جملهٔ اول روشن شود مدرس وارد مثال سوم شده است.

جمع‌بندی مهم: تو از «مهندسی» کلاس دور نیستی. اتفاقاً Retry، Timeout، SLO، Secret، Observability، Rate Limit، Capacity و Failure Mode همان چیزهایی هستند که در LLM Application هم حیاتی‌اند. فاصلهٔ فعلی بیشتر در Vocabulary + Python Glue Code است و قابل جبران است.

سه اشتباه ذهنی که باید همین ابتدا کنار بگذاریم

  1. «LLM مثل Search Engine یا Database است.» نیست؛ مدل بر اساس الگوها خروجی می‌سازد و ممکن است پاسخ خوش‌ظاهر اما غلط بدهد.
  2. «Agent یعنی خود مدل.» نه؛ Agent یک سیستم است: Model + Instructions + Tools + State + Control Loop + Guardrails.
  3. «برای ورود باید ریاضی سنگین بلد باشم.» برای ساخت Application در این مرحله، درک رفتاری و مهندسی API مهم‌تر از اثبات ریاضی Transformer است.
