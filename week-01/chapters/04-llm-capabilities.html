توانایی‌های LLM

کجا واقعاً ارزش ایجاد می‌کند؟

Transformation

بازنویسی، ترجمه، تغییر لحن، تبدیل متن آزاد به قالب مشخص و توضیح یک مفهوم برای مخاطب متفاوت.

Summarization

فشرده‌سازی گزارش، Ticket، Meeting Notes یا Logهای از قبل پاک‌سازی‌شده؛ با خطر حذف جزئیات مهم.

Extraction

استخراج Entity، تاریخ، رخداد، IP، Component، Severity یا Action Item از متن نیمه‌ساخت‌یافته.

Classification

دسته‌بندی Incident، Intent، Sentiment، نوع درخواست یا Route مناسب؛ باید با Dataset ارزیابی شود.

Generation

ساخت Draft، Runbook، Query، Test Case، کد اولیه یا توضیح؛ خروجی نیازمند Review است.

Reasoning-like Work

تقسیم مسئله، مقایسهٔ گزینه‌ها، پیشنهاد Plan و تحلیل چندمرحله‌ای؛ نه به معنای تضمین استدلال درست.

Code Assistance

توضیح کد، Refactor، تولید تست و یافتن Bug؛ ممکن است API یا Flag خیالی بسازد.

Multimodal

بسته به مدل: فهم تصویر، صوت، ویدئو یا تولید رسانه؛ هر نوع Input هزینه و Limit خاص دارد.

Tool Selection

در Agent می‌تواند تشخیص دهد کدام Tool را با چه Argumentی فراخوانی کند؛ اجرای واقعی را برنامه انجام می‌دهد.

مسئلهٔ مناسب برای LLM چه ویژگی دارد؟

  • ورودی یا خروجی آن زبان طبیعی، تصویر یا دادهٔ نیمه‌ساخت‌یافته است.
  • چند پاسخ قابل قبول وجود دارد و کیفیت را می‌توان با Rubric یا Evaluation سنجید.
  • خطا قابل کشف، قابل اصلاح یا در سطح ریسک پذیرفتنی است.
  • می‌توان Context معتبر، Tool یا Retrieval فراهم کرد.
  • ارزش انعطاف‌پذیری از نیاز به قطعیت بیت‌به‌بیت بیشتر است.
