سرفصل رسمیترجمهٔ سادهخروجی مورد انتظار
LLM capabilities and limits مدل چه کارهایی را خوب انجام می‌دهد و در چه جاهایی نباید به ظاهر مطمئنش اعتماد کرد؟ برای هر مسئله تشخیص بدهی LLM مناسب است، نیاز به ابزار/داده دارد یا اصلاً نباید استفاده شود.
Model ecosystem مدل‌های بزرگ/کوچک، Hosted / مدل با وزن باز، Reasoning/Fast، Multimodal/Embedding چه تفاوتی دارند؟ مدل را با معیار Accuracy، Cost، تأخیر، Privacy و قابلیت‌های API انتخاب کنی.
توکن، Context، Cost و تأخیر ورودی و خروجی چطور اندازه‌گیری و قیمت‌گذاری می‌شوند و زمان پاسخ از کجا می‌آید؟ بودجهٔ Context، هزینهٔ هر درخواست و p95 Latency را محاسبه و مانیتور کنی.
Python API refresher حداقل Python لازم برای خواندن فایل، ساخت JSON، صدا زدن SDK و پردازش پاسخ. یک Script تمیز و قابل‌اجرا بنویسی و خط‌به‌خط آن را بفهمی.
Environment variables and API usage کلید، مدل و Endpoint را بدون Hardcode کردن وارد برنامه کنی. Local، CI و Kubernetes را با الگوی Secret مناسب تنظیم کنی.
Basic error handling Timeout، Network Failure، Rate Limit، Auth و خطای خود کد را از هم جدا کنی. Retry محدود، Backoff، Logging و پیام خطای قابل‌فهم داشته باشی.
