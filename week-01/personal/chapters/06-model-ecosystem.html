اکوسیستم مدل‌ها

«بهترین مدل» وجود ندارد؛ مدل مناسب برای یک Workload مشخص وجود دارد

هنگام انتخاب مدل، فقط نام Provider یا عدد Benchmark را نگاه نکن. انتخاب مدل یک تصمیم معماری است و باید با کیفیت، Latency، هزینه، حریم خصوصی، قابلیت‌های Tool Use، Context Window و عملیات نگهداری سنجیده شود.

اول سه چیز را از هم جدا کن

Model

خود شبکهٔ عصبی و رفتار آن؛ مثلاً یک مدل سریع، Reasoning، Multimodal یا Embedding.

Provider

سرویسی که مدل را با API، ظرفیت، Billing، Policy و SLA در اختیار می‌گذارد. یک مدل ممکن است از چند Provider قابل دریافت باشد.

Application / Gateway

لایهٔ خودت برای Prompt، Routing، Retry، Cache، Audit، Evaluation و کنترل دسترسی. این لایه نباید بی‌دلیل به یک Provider قفل شود.

Hosted API در برابر Open-weight و Self-hosted

Hosted API

مزیت: شروع سریع، بدون GPU Ops، Scaling و به‌روزرسانی ساده‌تر، دسترسی به مدل‌های قوی.

هزینه: وابستگی به Provider، ملاحظات Data Residency، Rate Limit، Billing و تغییر نسخه.

Open-weight / Self-hosted

مزیت: کنترل بیشتر روی داده، Deployment، Version، Quantization و شبکهٔ بسته.

هزینه: GPU Capacity، Runtime، Scheduling، Autoscaling، Model Serving، Patch، Benchmark و On-call واقعی.

Open-source و Open-weight یکی نیستند. ممکن است وزن‌های مدل منتشر شده باشند اما Training Data، کد کامل یا License آن کاملاً باز نباشد. قبل از Production، Model Card، License، محدودیت استفادهٔ تجاری و شرایط توزیع را بخوان.

Model Serving در شبکهٔ سازمانی

ابزارهایی مانند vLLM می‌توانند برای برخی مدل‌های Open-weight یک API سازگار با قرارداد OpenAI ارائه کنند. این سازگاری به معنی رفتار یکسان مدل‌ها نیست؛ فقط شکل Endpoint و Request تا حدی مشابه می‌شود. Prompt، Tool Calling، Structured Output، Tokenizer و محدودیت‌ها باید جداگانه تست شوند.

روال درست انتخاب مدل

  1. Task را دقیق تعریف کن: ورودی، خروجی، زبان، اندازه، خطر و معیار موفقیت.
  2. Golden Set بساز: ۲۰ تا ۵۰ نمونهٔ واقعی با جواب یا معیار مورد انتظار.
  3. اول کیفیت را ثابت کن: مدل‌های کاندید را روی همان Dataset مقایسه کن.
  4. بعد Cost و Latency را کم کن: مدل کوچک‌تر، Prompt کوتاه‌تر، Cache یا Routing.
  5. نسخه را Pin و پایش کن: تغییر Model Snapshot یا Prompt می‌تواند Regression ایجاد کند.

انتخاب مدل شبیه انتخاب Database است. نمی‌گویی «قوی‌ترین Database دنیا را بده»؛ می‌پرسی Workload چیست، Consistency چقدر مهم است، Query Pattern چیست، چه SLA و چه تیم عملیاتی داریم. مدل هم همین‌طور است.
