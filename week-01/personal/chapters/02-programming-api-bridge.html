پل ورود: واژه‌های برنامه‌نویسی و API

چیزهایی که کلاس معمولاً سریع از کنارشان رد می‌شود

یک LLM Application در ساده‌ترین حالت، یک برنامهٔ Python است که داده را آماده می‌کند، یک Request به یک سرویس می‌فرستد، Response را می‌گیرد و آن را به فرم قابل استفاده تبدیل می‌کند. مدل ممکن است بسیار پیچیده باشد، اما Glue Code اطرافش معمولاً از همین مفاهیم تشکیل شده است.

Program / Script
فایل یا مجموعه فایل‌هایی که دستورهای قابل اجرا دارند؛ مثلاً incident_brief.py.
Module
یک فایل Python قابل Import. مثلاً sanitizer.py که تابع حذف Secret دارد.
Package
مجموعه‌ای از Moduleها که با pip نصب می‌شود؛ مانند openai یا python-dotenv.
Virtual Environment
محیط ایزولهٔ Dependencyها؛ شبیه Namespace کوچک برای پکیج‌های Python یک پروژه.
API
قرارداد ارتباط بین دو نرم‌افزار: Endpoint، روش احراز هویت، شکل Request، شکل Response و Errorها.
SDK
کتابخانه‌ای که جزئیات خام HTTP را برای یک API ساده می‌کند؛ مثلاً به‌جای ساخت Header و JSON دستی، تابع Python صدا می‌زنی.
JSON
فرمت متنی برای تبادل داده؛ Object شبیه dict و Array شبیه list در Python است.
Request / Response
درخواست ارسالی و پاسخ دریافتی. هر دو می‌توانند Header، Body، Status Code و شناسهٔ ردیابی داشته باشند.
Exception
شیء نشان‌دهندهٔ خطا در زمان اجرا؛ با try/except مدیریت می‌شود.
Sync / Async
در Sync برنامه تا جواب منتظر می‌ماند؛ در Async می‌تواند هم‌زمان کارهای دیگر را جلو ببرد. هفتهٔ اول با Sync شروع می‌کنیم.

API Contract شبیه Contract یک Kubernetes CRD یا Schema یک Helm Values است. اگر فیلد اشتباه، نوع دادهٔ غلط یا Credential نامعتبر بدهی، سرویس با Status مشخص رد می‌کند. SDK فقط Client خوش‌دست‌تری برای همین قرارداد است؛ جادو نیست.
