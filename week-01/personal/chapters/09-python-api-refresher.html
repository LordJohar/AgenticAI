ساخت محیط پروژه

Linux / macOS

Function: کوچک‌ترین واحد قابل آزمون

def calculate_error_rate(errors: int, total: int) -> float:
    """Return errors / total and avoid division by zero."""
    if total <= 0:
        return 0.0
    return errors / total

rate = calculate_error_rate(errors=21, total=1000)

Type Hintها مانند int و float الزام Runtime نیستند، ولی خوانایی، IDE و Static Analysis را بهتر می‌کنند. Docstring نیز قرارداد Function را توضیح می‌دهد.

payload = {

Import و نقطهٔ شروع برنامه

import os
from pathlib import Path


def main() -> int:
    print("program started")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

الگوی if __name__ == "__main__" باعث می‌شود main() فقط هنگام اجرای مستقیم فایل اجرا شود، نه وقتی فایل از برنامهٔ دیگری Import می‌شود. خروجی عددی نیز Exit Code برنامه است؛ 0 یعنی موفقیت.

چطور یک تکه کد Python را بخوانی؟

  1. از پایین فایل، نقطهٔ اجرای main() را پیدا کن.
  2. ورودی‌ها را پیدا کن: Argument، Environment Variable، File یا API.
  3. Functionها را یکی‌یکی بر اساس ورودی و خروجی بخوان.
  4. مسیر خطا را جدا از مسیر موفقیت دنبال کن.
  5. در پایان Side Effectها را مشخص کن: File Write، Network Call، Database یا Command.
تمرین فوری: فایل 01_python_api_refresher.py را اجرا کن، سپس نام Service و تعداد Eventها را تغییر بده و خروجی را پیش‌بینی کن.
فصل قبل: Cost و Latency فهرست فصل بعد: Environment Variables و اولین API Call
