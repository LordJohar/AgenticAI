تمرین مفهومی ۱

چرا یک LLM می‌تواند پاسخ بسیار روان اما اشتباه بدهد؟

پاسخ پیشنهادی

هدف پایهٔ مدل تولید دنبالهٔ محتمل Tokenها بر اساس الگوهای یادگرفته‌شده است، نه اجرای Query قطعی روی Database حقیقت. روان بودن و درست بودن دو Metric متفاوت‌اند؛ برای Fact باید Evidence، Retrieval، Tool و Evaluation اضافه شود.

تمرین مفهومی ۲

فرق Context با Memory چیست؟

پاسخ پیشنهادی

Context اطلاعات داخل Request جاری است. Memory معمولاً خارج از مدل در Database یا Store نگه داشته می‌شود و Application هنگام نیاز بخشی از آن را دوباره به Context می‌آورد.

تمرین مفهومی ۳

برای Classification ساده، چرا شروع مستقیم با بزرگ‌ترین Reasoning Model تصمیم خوبی نیست؟

پاسخ پیشنهادی

ممکن است Latency و Cost اضافه بدهد بدون افزایش ارزش. ابتدا معیار کیفیت و Dataset می‌سازیم، سپس کوچک‌ترین مدلی را انتخاب می‌کنیم که Threshold را پاس کند.

تمرین محاسباتی

با نرخ فرضی $3 / 1M input tokens و $12 / 1M output tokens، هزینهٔ Request دارای ۱۰٬۰۰۰ Token ورودی و ۲٬۰۰۰ Token خروجی چقدر است؟

پاسخ پیشنهادی
(10,000 / 1,000,000 × 3) + (2,000 / 1,000,000 × 12) = $0.054

تمرین Retry

برای هر مورد بگو Retry می‌کنی یا نه: Key اشتباه، Timeout، HTTP 503، Quota تمام‌شده، JSON ورودی خراب.

پاسخ پیشنهادی

Key اشتباه: خیر؛ Timeout: محدود و با Backoff؛ 503: محدود و با Jitter؛ Quota تمام‌شده: خیر؛ JSON خراب: خیر. قبل از Retry باید Idempotency و سقف زمان/هزینه نیز بررسی شود.

Labهای عملی

  1. 01_python_api_refresher.py را اجرا و یک فیلد تازه به خروجی اضافه کن.

  4. Timeout را عمداً بسیار کوتاه کن و مسیر Error را مشاهده کن؛ بعد مقدار منطقی را برگردان.
  5. قالب Output Prompt را تغییر بده تا خروجی JSON بخواهد؛ سپس فکر کن چگونه JSON را Validate می‌کنی.
