# مسیر شخصی‌سازی‌شدهٔ هفتهٔ اول

این پوشه عمومی است؛ واژهٔ «شخصی» فقط یعنی محتوا برای یک مسیر یادگیری مشخص و با تکیه بر پیش‌زمینهٔ DevOps/SRE نوشته شده است. مطالب این بخش را نباید عین گفتهٔ مدرس یا جزوهٔ رسمی کلاس در نظر گرفت.

## محتوا

- `index.html`: فهرست ۱۹ فصل تکمیلی؛
- `chapters/`: آموزش مفهومی و پروژه‌محور؛
- `examples/`: مثال‌های Python و Incident Brief CLI؛
- `exercises/`: تمرین و پاسخ تشریحی؛
- `progress.json`: وضعیت اولیهٔ مسیر مطالعه؛
- `standalone.html`: نسخهٔ تک‌فایلی و آفلاین؛
- `build_standalone.py`: بازسازی نسخهٔ تک‌فایلی از فصل‌ها؛
- `QA.md`: گزارش کنترل کیفیت بسته.

## مطالعه

فایل [index.html](index.html) را باز کنید و فصل‌ها را به‌ترتیب بخوانید. برای مرور سریع یا انتقال به دستگاه دیگر، [standalone.html](standalone.html) مناسب است.

## بازسازی نسخهٔ تک‌فایلی

از ریشهٔ مخزن اجرا کنید:

```bash
python week-01/personal/build_standalone.py
```
