# هفتهٔ دوم — Prompt، Context و تعامل ساختاریافته

این پوشه، هم جزوهٔ پیش‌خوانیِ هفتهٔ دوم بوت‌کمپ Agentic AI و هم بازنویسی آموزشیِ جلسه‌های ۵ و ۶ شهریور را نگه می‌دارد. پیش‌خوانی با تکیه بر سرفصل رسمی ساخته شده و جزوهٔ کلاس پس از بازبینی ویدئو، رونویسی زمان‌دار و اسلایدها به آن افزوده شده است.

## راه شروع

1. [صفحهٔ ورودی هفته](index.html) را باز کنید.
2. [راهنمای مطالعهٔ تفصیلی](study-guide/index.html) را از فصل صفر تا فصل یازده بخوانید.
3. [جزوهٔ مشترک جلسات کلاس](class-notes/index.html) را بخوانید؛ این بخش، ترتیب و مثال‌های تدریس‌شده را کنار توضیح پایه قرار می‌دهد.
4. در هر فصل، تیک «خواندم» را بزنید. پیشرفت فقط در مرورگر خودتان ذخیره می‌شود و Server لازم ندارد.
5. سپس سراغ تمرین‌های همان هفته بروید. پوشهٔ کدهای تمرین و Snapshot صفحه‌های سؤال، عمداً در Git منتشر نمی‌شوند.
