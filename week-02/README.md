# هفتهٔ دوم — Prompt، Context و تعامل ساختاریافته

این پوشه، جزوهٔ پیش‌خوانیِ هفتهٔ دوم بوت‌کمپ Agentic AI است. این جزوه با تکیه بر سرفصل رسمی ساخته شده و هنوز جایگزین بازنویسی جلسه‌ها یا ویدئوها نیست؛ بعد از دریافت ویدئوها، نکته‌ها، مثال‌ها و ترتیب تدریس استاد به آن افزوده می‌شود.

## راه شروع

1. [صفحهٔ ورودی هفته](index.html) را باز کنید.
2. [راهنمای مطالعهٔ تفصیلی](study-guide/index.html) را از فصل صفر تا فصل یازده بخوانید.
3. در هر فصل، تیک «خواندم» را بزنید. پیشرفت فقط در مرورگر خودتان ذخیره می‌شود و Server لازم ندارد.
4. سپس سراغ تمرین‌های همان هفته بروید. پوشهٔ کدهای تمرین و Snapshot صفحه‌های سؤال، عمداً در Git منتشر نمی‌شوند.

## سرفصل‌های پوشش‌داده‌شده

خود ویدئوها، فایل‌های خام سؤال، کد پاسخ تمرین‌ها، environment محلی و هر دادهٔ شخصی بیرون از Git می‌مانند. اینجا فقط جزوهٔ آموزشیِ قابل‌اشتراک قرار می‌گیرد.
