# جزوهٔ پیش‌نیاز مفهومی Agentic AI

این بخش، پیش‌نیاز مشترک تمام هفته‌های دوره است. مخاطب آن کسی است که با واژه‌هایی مانند Neural Network، gradient، Softmax، embedding، Attention و Transformer آشنایی قبلی ندارد.

## روش مطالعه

1. [نسخهٔ HTML تعاملی](index.html) را از ابتدا و به‌ترتیب بخوانید.
2. مثال‌های عددی را روی کاغذ دوباره محاسبه کنید.
3. پس از هر فصل، بدون نگاه‌کردن به متن به پرسش «آیا می‌توانم با زبان خودم توضیح بدهم؟» پاسخ دهید.
4. فقط بعد از جاافتادن فصل Softmax وارد Attention شوید؛ Softmax درون Attention نقش مستقیم دارد.

## قرارداد زبان

متن فارسی است، اما اصطلاحات تخصصی مانند `logit`، `gradient`، `embedding`، `Attention`، `Transformer` و `hallucination` به انگلیسی باقی مانده‌اند تا هنگام مطالعهٔ مقاله، کد و مستندات رسمی قابل‌شناسایی باشند.
