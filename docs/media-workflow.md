# روش عمومی تبدیل ویدئوی کلاس به جزوه

این سند ابزارها و جریان کار را توضیح می‌دهد، نه محیط اجرایی یا مشخصات سیستم یک فرد را. ویدئو، Transcript خام، مدل دانلودشده و virtual environment باید محلی بمانند.

## ابزارهای پیشنهادی

- **FFmpeg یا PyAV:** خواندن container، استخراج صوت و نمونه‌برداری از فریم‌ها؛
- **Faster-Whisper:** رونویسی زمان‌دار صوت به‌صورت محلی؛
- **مدل Whisper چندزبانه:** برای جلسه‌های فارسی و اصطلاحات انگلیسی؛
- **مرورگر:** کنترل نهایی HTML، فونت، راست‌به‌چپ و لینک‌ها.

GPU اختیاری است. Faster-Whisper روی CPU هم اجرا می‌شود، اما زمان پردازش به اندازهٔ مدل و طول ویدئو بستگی دارد. مستندات عمومی نباید شامل مدل لپ‌تاپ، ظرفیت حافظه یا مسیرهای شخصی سیستم باشد.

## قرارداد پوشه‌های محلی

مسیرهای زیر در `.gitignore` قرار دارند و نمونهٔ محتوا هستند، نه الزام:

```text
CLass/                      فایل‌های اصلی ویدئو
.local/transcription/
├── venv/                   محیط Python
├── models/                 مدل‌های دانلودشده
└── work/                   Transcript، فریم و خروجی میانی
```

## جریان کار

1. با FFmpeg/PyAV مدت، codec، رزولوشن و audio stream را بررسی کنید.
2. هر ۵ تا ۱۰ دقیقه یک فریم زمان‌دار بسازید تا مرز اسلاید و دمو مشخص شود.
3. صوت را با زبان فارسی و timestamp رونویسی کنید.
4. اصطلاحات فنی را با اسلاید و صوت بازبینی کنید؛ Transcript خودکار منبع نهایی نیست.
5. به‌جای انتشار متن خام، توضیح آموزشی تازه، Timeline، ابهام‌ها و تمرین بسازید.
6. HTML را با فونت فارسی، `dir="rtl"` و جهت چپ‌به‌راست برای code آماده کنید.
7. پیش از commit، فایل‌های staged را از نظر رسانه، Secret، مسیر محلی و مشخصات دستگاه بررسی کنید.

## نمونهٔ نصب مستقل

```bash
python -m venv .venv
python -m pip install faster-whisper av
```

نسخه‌ها را برای استفادهٔ تیمی pin کنید. اگر شتاب GPU لازم است، runtime سازگار با سیستم خودتان را طبق مستندات رسمی CTranslate2 نصب کنید.
